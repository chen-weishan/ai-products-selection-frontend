AI 任務中心運作架構與預算排程說明

A 軌 REST 直連配額池 (70%)

專為全量綜合分析與常態批次任務設計，直連 OpenRouter mistral 模型。系統具備品項本機結果快取機制，若資料無異動直接跳過外部呼叫，大幅減少重複 token 成本。

B 軌 opencode + MCP 探索池 (20%)

專為市場即時尋源、生命週期推估與即時競品探索設計。經由 Model Context Protocol (MCP) 串聯外部搜尋與數據工具，全域併發限制上限鎖定為 5。

重試與校準專用池 (10%)

當批次或探索任務發生外部超時或網路抖動時，提供子項目粒度修復機制。點擊「重跑失敗」將自動提取失敗品項由 RETRY 池執行，不重複計費已成功品項。

非同步狀態機與中斷控制

任務生命週期為 PENDING → RUNNING → SUCCEEDED / FAILED / PARTIAL。若任務中途執行「取消」，已處理之品項結果完好保留，未排入之品項立即釋放額度。
